# 🐾 GachaSwipe Web Matrix

The web-native companion to **GachaSwipe**, built with React, Vite, Dexie.js (offline-first IndexedDB), and BYOK NanoGPT AI synthesis.

🌐 **Live URL**: [https://gachaswipe.com](https://gachaswipe.com)

---

## ✨ Features

- **Swipe & Deck Mechanics**: Smooth mobile-optimized swipe gestures (Like, Pass, Rewind).
- **Offline-First Storage**: Local IndexedDB storage powered by Dexie.js with zero cloud dependency.
- **BYOK AI Synthesis**: Bring Your Own Key integration for NanoGPT character generation and Flux image generation.
- **M.I.K.A. Cloud Vault**: Storage quota indicator, key test handshake, and optional Supabase sync backend.
- **Web Audio Integration**: WaveSurfer audio waveforms and cyber-synth soundscapes.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
